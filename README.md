# Soundtec - Profesjonell Lydteknologi

En moderne, ultra-profesjonell nettside for Soundtec - Norges ledende leverandør av profesjonelle lydløsninger.

## Funksjoner

- **Moderne Design**: Rent, profesjonelt design med gradient-effekter og moderne typografi
- **Fullt Responsiv**: Optimalisert for alle enheter fra mobil til desktop
- **Smooth Animasjoner**: Elegante scroll-animasjoner og overganger
- **SEO-optimalisert**: Semantisk HTML5 struktur og optimaliserte metatags
- **Høy Ytelse**: Optimalisert CSS og JavaScript for rask lastetid
- **Tilgjengelighet**: WCAG-kompatibel med riktig ARIA-labels

## Teknologier

- HTML5
- CSS3 (Custom Properties, Flexbox, Grid)
- Vanilla JavaScript (ES6+)
- Google Fonts (Inter)

## Seksjoner

1. **Hero** - Slående introduksjon med call-to-action
2. **Tjenester** - Oversikt over alle lydtjenester
3. **Prosjekter** - Referanseprosjekter med kategorier
4. **Om Oss** - Informasjon om Soundtec
5. **Kundeomtaler** - Testimonials fra fornøyde kunder
6. **Kontakt** - Kontaktskjema og kontaktinformasjon

## Installasjon

Ingen installasjon nødvendig. Åpne bare `index.html` i en nettleser.

For lokal utvikling med live reload:

```bash
# Med Python
python -m http.server 8000

# Med Node.js og http-server
npx http-server
```

Åpne deretter http://localhost:8000 i nettleseren.

## Tilpasning

### Farger
Alle farger er definert som CSS-variabler i `:root` i `css/styles.css`. Endre disse for å tilpasse fargepaletten:

```css
:root {
    --primary: #6366f1;
    --secondary: #06b6d4;
    /* ... */
}
```

### Innhold
Alt innhold kan enkelt endres direkte i `index.html`. Hver seksjon er tydelig markert med kommentarer.

### Bilder
Legg til bilder i `images/` mappen og oppdater bildestiene i HTML.
